# Русский язык · ЕГЭ 2027

Тренажёр на основе структуры [тренажёра Иры](https://github.com/mastermoskva/ira-pharma-trainer): те же темы, блоки вопросов, ошибки, статистика, экспорт/импорт прогресса и сброс. Адаптирован под задания 9 и 10.

## Запуск и публикация

Откройте `index.html` в браузере — сборка и сервер не нужны.

Для GitHub Pages: **Settings → Pages → Deploy from a branch → main → / (root) → Save**. После публикации адрес будет https://mastermoskva.github.io/ege-trenajer-/ . Публикация в этой задаче не включалась.

## Что внутри

- 150 авторских упражнений по трём предоставленным PDF: проверяемые и словарные гласные, чередования, О/Ё после шипящих, И/Ы после Ц, приставки, ПРЕ/ПРИ, И/Ы после приставок, Ъ/Ь.
- Выбор одного ответа, сопоставление и 12 заданий с выбором нескольких рядов. Есть объяснения и правильные ответы.
- Блоки по 10/20/50 вопросов или вся тема, случайный или исходный порядок, только новые или повтор пройденных.
- Ошибки сохраняются отдельно; правильный ответ удаляет вопрос из ошибок. Кнопка «Не знаю» отправляет вопрос на повтор.
- Мини-тесты: выбор нескольких тем, количества и пула (все/новые/ошибки). Вопросы выбираются случайно без повторений. Сохранённая подборка хранит конкретные вопросы; при запуске меняется их порядок. Подборку можно удалить, сохранив статистику ответов.
- Автосохранение, экспорт и импорт JSON вместе с подборками. Прогресс хранится только в этом браузере, синхронизации между устройствами нет. Для переноса скачайте файл прогресса.
- Адаптация к телефону и системной тёмной теме, клавиши 1–5 для одиночного выбора.

Материалы предназначены для подготовки к ЕГЭ 2027, но не являются официальной демоверсией или КИМ 2027. Остальные задания экзамена пока не добавлены: предоставленные файлы посвящены только заданиям 9–10. Учебные упражнения составлены по теории, а не скопированы как готовый экзаменационный банк.

## Материалы и редактирование

См. [SOURCES.md](SOURCES.md). Вопросы находятся в `index.html` (массив `QUESTIONS`); читаемая копия банка — `questions.json`. При изменении банка обновляйте обе копии, сохраняйте номера существующих вопросов: к ним привязаны прогресс и подборки.

Проект статический, без сторонних запросов, аккаунтов и зависимостей во время работы. HTML можно сохранить и использовать без интернета.

## Проверки

Для разработчика: `npm ci`, затем `npm test` (Node.js 22+). Тесты проверяют целостность банка, проверку ответов всех трёх типов, ошибки, подборки, восстановление данных, экранирование названий и сброс. Зависимости нужны только для тестов.
